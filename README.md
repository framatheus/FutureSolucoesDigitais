# Future Soluções Digitais — Site comercial v3 (15/10/2026)

Atualização de página única, sem framework ou dependências de build. O arquivo `index.html` contém HTML, CSS e JavaScript.

## Como publicar no repositório atual

1. Abra https://github.com/framatheus/FutureSolucoesDigitais.
2. Substitua **somente o conteúdo do `index.html`** pelo arquivo deste pacote (preferencialmente em uma branch de revisão).
3. **Mantenha** no repositório a pasta `assets` e o arquivo `favicon.svg` existentes. As imagens dos projetos reais dependem desses recursos.
4. Confirme a publicação automática do GitHub Pages/Vercel configurado na conta e teste em celular.
5. Confirme os dados de WhatsApp e e-mail exibidos: são os contatos que já estavam publicados no site antigo, não um novo WhatsApp exclusivo.
