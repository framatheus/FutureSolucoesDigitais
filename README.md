# Future Soluções Digitais — Portfólio

Portfólio estático preparado para publicação gratuita no GitHub Pages.

## Publicar no GitHub Pages

1. Crie um repositório público no GitHub.
2. Envie todos os arquivos desta pasta para a raiz do repositório.
3. Abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch **main**, a pasta **/(root)** e clique em **Save**.
6. Aguarde alguns minutos. O GitHub exibirá o endereço publicado.

O arquivo principal precisa permanecer com o nome `index.html`.

## Estrutura

- `index.html`: conteúdo do portfólio.
- `style.css`: identidade visual e responsividade.
- `assets/`: foto e demonstrações anonimizadas dos projetos.
- `.nojekyll`: evita processamento desnecessário pelo Jekyll.
