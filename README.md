# Future Soluções Digitais — versão estática

## Publicação no Vercel

1. Extraia o ZIP.
2. Envie a pasta completa para um repositório GitHub.
3. No Vercel, escolha **Add New → Project** e importe o repositório.
4. Em **Framework Preset**, selecione **Other**.
5. Deixe os campos de build vazios e publique.

O arquivo `index.html` precisa permanecer na raiz junto de `style.css`, `script.js`, `vercel.json`, `favicon.svg` e da pasta `assets`.
